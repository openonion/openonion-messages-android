# Support

OpenOnion Messages is community-supported open-source software.

## Questions and installation help

Search existing [GitHub Discussions][discussions] and issues first. If the
answer is not there, open a discussion with the Android version, phone model,
app version, and the step that failed. Remove phone numbers, SMS content,
pairing links, Agent addresses, credentials, and screenshots containing them.

## Bugs and feature requests

Use the repository's structured [issue forms][issues]. Include the smallest
reproduction using synthetic data and say whether the problem affects local
SMS, pairing, encryption, upload, deletion, or the Agent inbox.

## Security and privacy

Do not open a public issue for a vulnerability or privacy incident. Follow
[SECURITY.md](SECURITY.md) and email `security@openonion.ai`. Privacy questions
and deletion requests go to `privacy@openonion.ai`.

This project does not provide an emergency service or guarantee carrier SMS
delivery. The first stable release does not support MMS or RCS.
