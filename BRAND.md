# Brand

**OpenOnion Messages** is the Android SMS endpoint in the OpenOnion product
family. The product name always appears in full on first use; “Messages” is the
short UI label only where the OpenOnion context is already visible.

The lavender onion is the shared OpenOnion master mark. Messages uses that mark
with a warm-paper background and message-specific notification glyphs instead
of creating a second identity. Product language should emphasize an explicit,
private Agent inbox and avoid surveillance or authentication claims.

The Apache-2.0 license covers this repository's code and assets but does not
grant permission to imply that a modified build is an official OpenOnion
release. Forks should use a distinct application ID and presentation when
needed to avoid user confusion.
