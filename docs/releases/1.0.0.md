# OpenOnion Messages 1.0.0

OpenOnion Messages is a transparent, owner-controlled SMS inbox for people and
their AI Agents. It is an open-source Kotlin Android application and can become
the phone's default SMS handler. New inbound SMS is encrypted on the phone for
one explicitly paired ConnectOnion Agent; `oo-api` stores only ciphertext and
routing metadata.

## Included

- local SMS inbox, private notifications, and human-initiated sending;
- Android default-SMS role on Android 8.0 and newer;
- one-time, expiring Agent pairing with visible identity and revocation;
- libsodium sealed-box encryption on the phone;
- durable, idempotent upload with offline WorkManager retries;
- Agent read, wait, acknowledge, and local decryption tools; and
- owner-confirmed deletion from both Android and the server ciphertext inbox.

The interface uses the OpenOnion green, white, and black visual system in both
light and dark modes. It contains no analytics or advertising SDK.

## Security and privacy

The encrypted endpoints are the Android app and the target ConnectOnion
runtime. The storage service does not possess the decryption key. Decrypted SMS
is always returned to Agents with `trusted: false`; SMS text is input data, not
authority to perform an action.

The protocol has public cross-language vectors and a real hosted Android →
oo-api → PostgreSQL → ConnectOnion lifecycle test. It has not received an
independent cryptographic audit. Review the repository's privacy disclosure and
threat model before pairing a production phone.

## Compatible services

- `oo-api` v0.1.16 or newer, deployed at `https://oo.openonion.ai`;
- ConnectOnion v1.8.0a5 or newer for signed SMS pairing and inbox helpers.

ConnectOnion v1.8.0a5 is currently a preview SDK release. This does not change
the Android application's stable-version guarantees, but Agent projects must
opt in to that SDK version until the SMS helpers enter the next stable SDK.

## Known limitations

- MMS and RCS are not supported.
- Messages received before pairing are not uploaded retroactively.
- Agents cannot send SMS or automatically act on SMS content.
- The server necessarily learns the paired Agent address, device identity,
  ciphertext size, and ingestion/acknowledgement timing.
- Encryption ends when the Agent runtime deliberately gives plaintext to a
  model, plugin, log, or other service.

## Verify downloads

The GitHub Release contains a signed APK, signed AAB, and SHA-256 checksum file.
After downloading them:

```bash
sha256sum --check OpenOnion-Messages-v1.0.0-SHA256SUMS.txt
gh attestation verify OpenOnion-Messages-v1.0.0.apk \
  --repo openonion/openonion-messages-android
```

The expected Android application ID is `ai.openonion.messages`, version name
`1.0.0`, version code `1`, minimum Android API `26`, and target API `36`.
